# 캐릭터 레벨·SP 관리

경험치 획득은 아직 구현하지 않는다. 서버 내부의 `TownInstance::AdvancePlayerLevel`을 향후 레벨업 로직에서 호출할 수 있다. 레벨 변경과 SP 지급은 Town strand에서 수행되며, 같은 레벨이나 낮은 레벨 요청에는 SP를 다시 지급하지 않는다. 클라이언트 레벨업 요청 패킷은 없다.

사용자가 이번 범위를 **접속 중인 캐릭터 관리**로 지정했다. 레벨·SP·습득 정보는 TownServer의 플레이어별 메모리에 둔다. 마을/던전 전환 중에는 유지되고 접속 종료 시 사라진다. 프로필 파일 저장, 고정 접속 이름, 계정 기능은 추가하지 않는다.

서버 설정:

* `Data/CharacterProgression.json`: 초기 레벨 1, 초기 SP 0, 레벨업당 200 SP.
* `Data/SkillTrees.json`: 요구 레벨, 단계 간격 2, 고정 SP 비용, 선택적 최대 레벨, 선행 스킬, 공격력 증가량, 표시 정보.

캐릭터는 레벨 1/SP 0으로 접속한다. 아직 자동 레벨업 조건이 없으므로 기본 상태에서는 앞차기도 SP 부족으로 잠긴다. 향후 서버 레벨업 로직에서 `AdvancePlayerLevel(playerId, newLevel, callback)`을 호출하면 레벨 증가분만큼 SP가 지급되고 클라이언트와 던전에 전달된다. 레벨 2에 도달하면 200 SP가 지급되어 앞차기를 20 SP에 습득할 수 있다. 2단계는 캐릭터 레벨 3에 요구되며 비용은 다시 20 SP, 공격력은 30이다.

스킬 트리와 실행 스킬 카탈로그는 TownServer와 GameRoomServer에 같은 파일로 배포해야 한다. 새 스킬을 추가할 때 해당 스킬의 트리 노드도 추가한다. 누락 참조·선행 조건 순환·다른 캐릭터 선행 조건은 로드 단계에서 거절된다. `maxSkillLevel: null`은 기획상 상한 없음이며, 지정된 숫자는 최대 스킬 레벨이다. 직렬화 값과 계산에는 정수 범위 검증이 적용된다.
