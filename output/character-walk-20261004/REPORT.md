# 걷기 모션 수정

## 반영

* 클라이언트 `Assets/Images/Characters/player_walk.png` 교체
* Debug 실행 폴더의 같은 PNG 및 `Assets/Data/animations.ini` 동기화
* 10프레임, 5열 2행, 프레임당 0.088초 유지
* 생성 PNG 실제 치수는 1983 × 793이며, 기존 렌더러의 균등 셀 분할을 사용
* 프레임별 `anchor_xs`로 머리의 가로 흔들림 보정
* 행별 접지 기준과 표시 높이를 새 이미지의 실제 크기에 맞춤
* 이동 속도, 달리기 시트, 게임 로직 수정 없음

## 확인

* PNG RGBA 및 투명 배경 확인
* 10개 프레임의 픽셀 해시가 모두 서로 다름
* 알파 32 초과의 캐릭터가 각 셀 안에 들어가는 것 확인
* 원본과 Debug PNG·INI가 각각 일치
* 걷기 자세와 캐릭터 외형은 생성 시트로 시각 검토
* 실제 게임에서 반복 재생·접지·체감은 미확인. 재시작 후 확인 필요
