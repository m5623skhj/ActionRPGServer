## 처리 방법

도구 실제 출력은 모두 1672×941 RGB PNG였으며 요청 치수와 다릅니다.
일반방은 명시된 16:9 영역을 자른 뒤 Pillow NEAREST로 1280×720에 맞췄습니다.
입구/경비실/안뜰/회랑은 북쪽 장식이 이동 바닥에 내려오지 않도록 상단 일부와 좌우 가장자리를 잘랐습니다.
무기고는 중앙 북쪽 통로를 image_gen으로 넓힌 뒤 가장자리만 잘라 최종화했습니다.
보스방은 자르지 않고 NEAREST로 1600×900에 맞췄습니다. 원본 비율과 16:9의 미세한 차이가 있습니다.
원본 픽셀은 보존했으며 최종본에는 리사이즈에 따른 픽셀 선택 변화가 있습니다. 블러/팔레트 변경/캐릭터 합성은 하지 않았습니다.

## 배치 기준

1 이미지 픽셀 = 1 월드 단위, 방 좌상단 (0,0), 배경 scale=1 기준입니다.
- 입구: 동쪽 (1200,460), 바닥 x40..1240,y300..650.
- 경비실: 서/동 (80,460)/(1200,460), 바닥 x40..1240,y300..650.
- 안뜰: 서/동 (80,460)/(1200,460), 남 (640,640), 바닥 x40..1240,y230..650, 남 통로 x560..720,y600..700.
- 무기고: 북 (640,80), 바닥 x40..1240,y300..650, 북 통로 x560..720,y30..400.
- 회랑: 서/동 (80,460)/(1200,460), 바닥 x40..1240,y300..650.
- 왕좌방: 서 (80,570), 바닥 x40..1560,y300..820, 보스 예정 발 위치 (1100,560).

위 좌표는 던전 담당이 전달한 배치 계약입니다. 이미지에 충돌/이동 다각형이나 게이트 판정은 포함하지 않습니다.
