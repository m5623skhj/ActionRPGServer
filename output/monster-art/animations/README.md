# 몬스터 모션 이미지

내장 image_gen으로 승인된 몬스터 외형을 기준으로 생성한 투명 PNG 시트입니다.
각 시트의 재생 순서는 왼쪽 위부터 오른쪽으로 진행한 뒤 다음 줄로 이어집니다.

| 동작 | 프레임 | 재생 |
|---|---:|---|
| move | 8 | 반복 |
| hit | 4 | 일반 경직 후 복귀 |
| airborne | 8 | 띄워짐 → 추락 → 쓰러짐 → 기상 |
| attack | 8 | 준비 → 검 공격 → 회수 |
| death | 8 | 쓰러진 뒤 마지막 자세 유지 |

- `rusted_armor_soldier_*.png`: 일반 몬스터, 녹슨 갑옷병
- `fallen_citadel_warden_*.png`: 보스, 몰락한 성채 수호자
- `preview.html`: 이 폴더에서 열어 두 몬스터의 모션을 재생·정지하거나 프레임별로 확인
- `animations.json`: 원본 좌표, 프레임별 중심점, 권장 속도와 동작 구간
- `GENERATION.json`: 생성 도구, 선택한 원본 경로 및 실제 생성·보정 프롬프트
- `annotation-settings.json`: 중심점과 모션 간 크기 보정 기준

## 프레임 사용

생성된 시트는 정확한 등간격 격자가 아닙니다. PNG를 단순히 4×2 또는 2×2로
등분하면 검끝이나 쓰러진 몸이 잘릴 수 있습니다. `animations.json`의 프레임별
`sourceRect`를 사용하세요. 이 좌표는 원본 PNG에서 분석한 그림 경계에 여백을 포함합니다.
원본 이미지는 재샘플링하거나 픽셀을 이동하지 않고 그대로 보존했습니다.

`pivot`는 해당 sourceRect의 왼쪽 위를 기준으로 한 바닥 중심점입니다.
그릴 때 목적지 중심에서 `pivot × scale`을 빼서 배치합니다.
중심점은 외형을 보고 지정한 권장값이며, 실제 게임에서의 접지점 확인은 남아 있습니다.
`scaleToMovement`는 같은 몬스터의 이동 시트와 다른 동작의 크기를 맞추기 위한 기준입니다.

프레임 번호는 0부터 시작합니다.

- 공격: 준비 0~3, 공격 4~5, 회수 6~7. 권장 타격 이벤트는 4번 프레임입니다.
- 에어본: 띄워짐 0~1, 공중 유지 2, 추락 3, 쓰러짐 4~5, 기상 6~7.
  공중의 높이·추락·바닥 접촉은 게임의 물리 상태로 구동하며, 공중 유지 프레임은 필요에 따라 유지합니다.
- 사망: 끝까지 재생한 뒤 마지막 프레임을 유지합니다.

미리보기는 비교를 위해 일반 몬스터 높이 200, 보스 높이 330으로 표시합니다.
에어본의 높이 변화도 미리보기용이며 실제 게임 물리를 구현한 것은 아닙니다.
이 파일과 동작 구간 정보는 이미지 전달용입니다. 기존 클라이언트의 애니메이션 설정,
몬스터 카탈로그, 서버 AI에는 아직 등록하지 않았습니다.

빌드·게임 실행 테스트는 수행하지 않았습니다.
