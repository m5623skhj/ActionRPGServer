# 점프력·공격 방향 클라이언트 적용 기준

2026-10-04. 사용자 승인: 초기 상승 속도에 2/3를 한 번만 적용하며 중력/이동 수치는 유지한다. 공격 시작 방향은 같은 최대 5발 연속 구간 동안 유지하고 이동 허용을 추가로 막지 않는다.

* 마을 변경 전 원본: 클라이언트 Character.h의 JUMP_SPEED=1035, GRAVITY=1800. 기존 Characters 자산의 characters.ini에 Default 및 Character1/2/3 jump_speed=690을 반영하고 로그인 캐릭터 ID별로 선택하도록 연결했다. 값이 없으면 Default를 사용한다. JUMP_SPEED 상수는 제거했고 실행 중 비율 곱셈은 없다.
* 던전 변경 전 원본: 서버 GameRoomServer/Data/Combat.json의 player.jump.speed=851.43, gravity=1200. 서버 담당의 567.62 반영과 완료 보고를 확인했다. 클라이언트 DungeonWorld/CombatRules 수신값과 state.verticalSpeed/height를 그대로 사용하고 추가 2/3를 곱하지 않는다.
* 기존 마을/던전의 속도 기준은 서로 다르다. 각 원본에 동일 2/3를 적용한다. 마을의 중력을 던전에 맞추거나 서로 다른 기존 수치를 합치지 않는다.
* 기존 JSON/SKL1의 shotPhase와 shotCount를 방향 잠금 기준으로 사용한다. Prepare/Fire/Recover 중에는 잠금, None이어도 0<shotCount<maxShots인 연속 입력 유예 동안에는 방향만 유지한다. 서버가 유예 종료 때 count=0으로 정리하면 정상 전환한다. 5발의 회수 단계가 끝나거나 취소되면 방향 잠금은 끝나며 기존 발수 제한/입력 유예는 유지한다. 신규 wire 필드는 도입하지 않는다.
* 로컬 던전의 공격/스킬 송신 직후에는 요청 sequence에 묶인 제한된 방향 예측을 사용한다. 거절/피격/초기화에 해제하고, 해당 입력 이후의 실제 공격/스킬 상태가 오면 서버 방향으로 넘긴다. 스킬 전환에 기존 잠금 방향을 이어받으며 예측 기간을 연장하지 않는다. 기존 입력 버퍼 250ms + 표시 예측 상한 250ms + 서버 tick 간격을 상한으로 두어 누락/버퍼 만료에 영구 잠금이 남지 않게 한다. 피해·발사 판정을 예측하지 않는다.
* 기본 공격 회복 취소는 기존 이동 허용을 유지한다. 같은 연속 공격으로 이어질 수 있는 유예의 방향을 보존한다. 점프/스킬의 명시적 공격 취소와 피격/초기화에서는 기본 공격 유예도 정리한다.

실제 소스 반영과 정적 확인을 완료했으며 변경 파일·미검증·서버 완료 대조 결과는 CLIENT_HANDOFF.md에 기록했다. 다른 채팅으로 직접 메시지를 보내지 않았다.
