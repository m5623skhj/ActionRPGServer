# 몬스터 정의 설치

GameRoomServer는 시작할 때 실행 파일 옆 `Data/Monsters/MonsterCatalog.json`을 읽습니다.
이 카탈로그는 던전 배치의 숫자 Data ID와 몬스터 편집기의 문자열 ID를 연결합니다.

```json
{
  "version": 1,
  "monsters": [
    { "dataId": 1, "definitionFile": "Dummy.ai.json", "monsterId": "Dummy" }
  ]
}
```

## 편집한 몬스터 등록

1. 몬스터 편집기에서 저장한 `.ai.json` 또는 승인 후 출력한 `.approved.ai.json`을
   이 폴더에 복사합니다. 편집기 문서 형식은 `schemaVersion: 1`입니다.
2. 카탈로그에 숫자 `dataId`, 파일명 `definitionFile`, 문서 내 몬스터의 `id`인
   `monsterId`를 등록합니다. 한 문서의 여러 몬스터도 각각 등록할 수 있습니다.
3. 던전 배치의 몬스터 Data ID를 카탈로그와 맞춥니다.
4. 빌드하면 프로젝트 Data 폴더가 실행 파일 옆으로 복사됩니다.
   실행 폴더를 직접 수정했다면 서버를 재시작하여 적용합니다.

- Data ID는 1~1,000,000이며 중복할 수 없습니다. 카탈로그는 최대 256개입니다.
- 파일명은 영문자로 시작하고 영문·숫자·밑줄·점·하이픈과 `.json` 확장자를 사용합니다.
  경로와 하위 폴더는 허용하지 않습니다.
- 문자열 ID는 대소문자를 구분합니다. 서버 기본 파일은 `Dummy`를 숫자 ID 1에 연결합니다.
- `maxHp`는 1~4,294,967,295의 정수여야 합니다. 생성 시 현재 HP도 이 값으로 설정됩니다.

## 로딩과 검증

서버는 이름·최대 HP·AI 그래프와 문서의 스킬·동작 정의를 읽습니다.
승인 기록의 `approval.status`에 의존하지 않고 문서 전체를 다시 검사합니다.
따라서 기본 Dummy처럼 초안 상태인 문서도 내용이 유효하면 로딩할 수 있습니다.

- 파일당 4MB, 참조한 정의 파일 합계 64MB 제한
- 문서별 몬스터 256개, 스킬·동작 각각 2048개 제한
- AI 상태 512개, 연결 2048개, 조건 깊이 8단계·항목 128개 제한
- ID 중복, 없는 상태·스킬·동작 참조, 잘못된 숫자와 지원하지 않는 동작·조건 거부
- 도달할 수 없는 상태, 중복 우선순위, 하위 전환을 가리는 Always 조건 거부
- 루프 동작의 완료 전환과 시간을 소비하지 않는 즉시 순환 거부
  (업데이트나 실제 대기를 거치는 순환은 허용)

카탈로그 또는 정의 파일에 문제가 있으면 오류를 출력하고 서버 시작을 중단합니다.
던전에서 미등록 몬스터 ID를 참조하면 해당 던전은 사유를 출력하고 제외합니다.

정의는 서버 시작 시 한 번 읽어 변경 불가능한 객체로 공유합니다.
각 던전은 배치마다 instance ID와 독립된 HP·위치·초기 AI 상태를 생성합니다.
초기 AI 상태는 `ai.initialNodeId`입니다. 이후 개체 상태 변경은 던전 인스턴스인 GameRoom의 strand에서
처리해야 합니다.

서버에는 AI 그래프 실행과 기본 전투 판정 코드가 추가되었습니다. 서버 전용 `Data/Combat.json`의
몬스터 프로필과 스킬 타격 정의도 필요합니다. Dummy ID 1은 대기를 유지하고,
ID 2·3에는 최소 감지·추적·공격·회복·귀환 패턴과 서버 스킬 효과를 연결했습니다.
HP·피해량 등은 통합용 임시값이며 드랍·보상 지급은 아직 구현하지 않았습니다.
현재 클라이언트 소스에는 월드·몬스터/HP 상태 수신과 전투 입력/표시 경로가 있습니다.
클라이언트 자산은 ActionRPGClient에서 관리하며 이 폴더에는 서버 정의만 설치합니다.
이번 문서 작업에서 빌드·실제 AI/전투 실행은 확인하지 않았습니다.
서버 계약과 검증 범위는 [전투 연결 안내](../../COMBAT_PROTOCOL.md)를 참고하세요.
던전 배치는 [던전 데이터 안내](../Dungeons/README.md), 인증과 실행 전제는
[서버 README](../../../../README.md)를 참고하세요.
